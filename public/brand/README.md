# Progressive Web Office — brand

![Progressive Web Office](banner.png)

## The logo

Three fanned sheets: the **document** in front (white, blue lines), the
**spreadsheet** (green) and the **presentation** (orange) behind it — one
suite, open formats, in the browser.

| File | Use |
| --- | --- |
| [`icon.svg`](icon.svg) / [`icon.png`](icon.png) | App icon (square; the platform rounds it if it wants), favicon, logo inside the app |

## Type

The name is set in the system sans-serif (Inter, Segoe UI, Roboto,
Helvetica Neue, Arial), bold, slightly tightened: **Progressive Web Office**.
The short name is **PWO**.

## Usage

- Keep clear space around the logo of at least a quarter of its width.
- Do not recolour, stretch, rotate or add effects to the sheets.
- On a light background, use `icon.svg` (its own navy square) rather than
  the bare `mark.svg`.
- Smallest size: 16 px for the icon, 24 px for the bare mark.
