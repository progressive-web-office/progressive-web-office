# Reading and reviewing

Word and OpenDocument texts, Markdown notes and PDF files can be read the
same way: page by page or scrolled, one or several pages side by side, with
the same buttons and keyboard shortcuts, and comments added as you read.

## Review mode of text documents

Click **📖 Review** in the toolbar of a text document (or press
<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>R</kbd>). The editing toolbars make way
for the review bar:

- the document is laid out as pages, like a PDF file; a page break in the
  document starts a new page;
- the text cannot be changed, but it can be selected and **commented**
  (<kbd>c</kbd>, or 💬); comments are listed beside the pages and saved with
  the document as usual (Word, OpenDocument, Markdown);
- **✎ Edit** (or <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>R</kbd> again) goes back to
  editing.

The pages of the review mode are a screen layout (US Letter, the width of
the editor's page): they do not always match the pages of the printed
document.

PDF files are always shown this way: the same review bar is part of the PDF
viewer, where comments are highlights and notes (see [PDF](./pdf)).

## Page by page or scrolled

**📄 Page by page** shows one spread at a time, with no scrolling: the next
spread replaces it (<kbd>j</kbd>, <kbd>Space</kbd>, the mouse wheel at the
bottom of the page…). **📜 Scroll** shows the pages one after the other.
<kbd>s</kbd> switches between them. Choose 1, 2, 3, 4 (or 6 for PDF files)
pages side by side, the whole page (↕) or the width (↔). The choices are
remembered.

## Full screen without distractions

⛶ (or <kbd>f</kbd>) puts the browser in full screen and hides everything but
the pages, the review bar and the comments. <kbd>Esc</kbd> or <kbd>f</kbd>
leaves it.

## Keyboard shortcuts

Single keys, when the cursor is not in a field (⌨ or <kbd>?</kbd> lists them):

| Keys | Action |
|------|--------|
| <kbd>j</kbd> <kbd>n</kbd> <kbd>Page Down</kbd> <kbd>Space</kbd> <kbd>→</kbd> | Next page (or spread) |
| <kbd>k</kbd> <kbd>p</kbd> <kbd>Page Up</kbd> <kbd>Shift</kbd>+<kbd>Space</kbd> <kbd>←</kbd> | Previous page |
| <kbd>g</kbd> <kbd>Home</kbd> / <kbd>G</kbd> <kbd>End</kbd> | First / last page |
| <kbd>+</kbd> <kbd>-</kbd> | Zoom in / out |
| <kbd>w</kbd> / <kbd>h</kbd> <kbd>0</kbd> | Fit the width / the whole page |
| <kbd>1</kbd> … <kbd>4</kbd> | Pages side by side |
| <kbd>s</kbd> | Page by page or scrolled |
| <kbd>c</kbd> | Comment the selection (PDF: highlight it, or place a note) |
| <kbd>]</kbd> / <kbd>[</kbd> | Next / previous comment |
| <kbd>/</kbd> | Find |
| <kbd>f</kbd> | Full screen without distractions |
| <kbd>?</kbd> | The list of shortcuts |
