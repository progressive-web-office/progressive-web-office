# Brand

![Progressive Web Office](https://progressive-web-office.github.io/brand/banner.png)

## The logo

<img src="/logo.svg" alt="The logo of Progressive Web Office: three fanned sheets" width="96" height="96" style="float: right; margin: 0 0 12px 16px">

Three fanned sheets: the **document** in front (white, blue lines), the
**spreadsheet** (green) and the **presentation** (orange) behind it — one
suite, open formats, in the browser. The same square icon is the icon of
the installed application, the favicon, and the logo inside the application
and this documentation.

The sources are in the
[brand folder](https://github.com/progressive-web-office/progressive-web-office.github.io/tree/main/brand)
of the organisation's site. In this repository, `public/icon.svg` and
`public/icon-maskable.svg` are copies; `just icons` renders the PNG icons of
the application from them.

In the dark theme the accent of the application is `#6ea2f5`.

## Type

The name is set in the system sans-serif (Inter, Segoe UI, Roboto, Helvetica
Neue, Arial), bold, slightly tightened: **Progressive Web Office**. The short
name is **PWO**.

## Usage

- Keep clear space around the logo of at least a quarter of its width.
- Do not recolour, stretch, rotate or add effects to the sheets.
- On a light background, use `icon.svg` (its own navy square) rather than
  the bare `mark.svg`.
- Smallest size: 16 px for the icon, 24 px for the bare mark.
